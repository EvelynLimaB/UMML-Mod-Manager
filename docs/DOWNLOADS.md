# Downloads and release counters

[![All release asset downloads](https://img.shields.io/github/downloads/EvelynLimaB/Uma-Mod-Manager/total?label=all%20release%20downloads)](https://github.com/EvelynLimaB/Uma-Mod-Manager/releases)
[![Alpha19 downloads](https://img.shields.io/github/downloads/EvelynLimaB/Uma-Mod-Manager/v0.2.0-alpha.19/total?label=alpha19%20downloads)](https://github.com/EvelynLimaB/Uma-Mod-Manager/releases/tag/v0.2.0-alpha.19)

GitHub's repository release list does not display aggregate download counts. The
badges above read the public release-asset counters and provide the missing total
and per-release views without collecting separate analytics.

The count covers uploaded release assets such as the Windows portable ZIP,
Debian package, AppImage, and checksum files. GitHub's automatically generated
**Source code (zip)** and **Source code (tar.gz)** links are not normal release
assets and do not expose the same asset download counter.

These numbers are useful for rough adoption feedback, not unique-user analytics:

- repeated downloads count repeatedly;
- automated clients can count;
- mirrors and copied files are invisible;
- deleting or replacing a release asset can discard its historical counter;
- the project does not add user tracking merely to obtain prettier numbers.

Permanent packages remain on the [Releases page](https://github.com/EvelynLimaB/Uma-Mod-Manager/releases).
Short-lived exact-head build artifacts remain under GitHub Actions and are not
included in release-asset totals.
